- **design/**: Design documents and architecture notes

- **playbooks/**: Operational playbooks and procedures

## Getting Started

Use docmgr commands to manage this workspace:

- Add documents: `docmgr doc add --ticket RM-MATH-PREPROCESS --doc-type design-doc --title "My Design"`
- Import sources: `docmgr import file --ticket RM-MATH-PREPROCESS --file /path/to/doc.md`
- Update metadata: `docmgr meta update --ticket RM-MATH-PREPROCESS --field Status --value review`
